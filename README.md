# Cash — учёт финансов (Android + Windows)

Приложение повторяет таблицу `info-tasks/table.jpg` и делает её удобнее.
Один исходный код на Flutter собирается в **APK для Android** и **нативное
приложение для Windows 10/11**. Устройства синхронизируются **напрямую по
локальной сети** — без интернета и внешних серверов.

## Что умеет

| В таблице | В приложении |
|---|---|
| Курс, В месяц €, В гривнах | Вкладка «Период» → «Доход» (гривны считаются сами) |
| На квартиру, Коммуналка | «Обязательные расходы» — любое количество строк |
| Плачу (кредиты) | «Кредиты (плачу)» — вычитается из бюджета |
| Таблица счётчиков (вода, свет, отопление) | Вкладка «Коммуналка»: показания, тарифы, сумма по умолчанию |
| Остаток, В день | «Итог» и плитки на главной |
| Столбцы День / Потрачено / Остаток | Таблица дней на вкладке «Бюджет»; нажмите на день — список трат |
| Потрачено, Осталось | Плитки на главной |
| Кредиты / Проценты / Внес / Всего | Вкладка «Кредиты»: платежи, внесённые суммы, разница |

Что добавлено сверх таблицы:

- **Главное число дня** — «Остаток на сегодня»: сколько ещё можно потратить сегодня.
  При перерасходе показывает, в какой день вы выйдете в плюс, если не тратить.
- **Лимит с учётом трат** — сколько в день можно тратить до конца периода.
- Несколько расходов за день с комментариями, быстрые подсказки частых комментариев.
- Ввод выражений: `500+250` → 750.
- Отмена удаления, история периодов, «Создать следующий период» копирует настройки.
- Резервные копии в файл; восстановленная копия заменяет данные на всех устройствах.
- Тёмная тема, крупный интерфейс на телефоне, двухколоночный — на ПК.
- На Windows: `Ctrl+N` — новый расход, `Ctrl+1…5` — вкладки.

При первом запуске можно нажать **«Перенести данные из таблицы»** — загрузится
текущий период 10.10–09.11.2026 со всеми суммами из скриншота. Делать это можно
на обоих устройствах: дублей не будет.

## Коммуналка

Строка «Коммуналка» в обязательных расходах периода считается сама:

- **до 28-го** — стоит **сумма по умолчанию** (вкладка «Коммуналка» → «Сумма по
  умолчанию»). Вводится один раз и действует, пока её не поменяете: летом
  ~2000 ₴, в отопительный сезон 4–5 тыс.;
- **28-го** на главной появляется напоминание «Пора снять показания». После ввода
  показаний (ванна, кухня, электричество и отопление, если начислено) в бюджет
  периода подставляется точная сумма.

К периоду относятся показания, снятые внутри него: для периода 10.10–09.11 — это
показания 28.10. Расчёт как в таблице:

```
Вода  = (Δванна + Δкухня) × (куб вход + куб выход) + абон вход + абон выход
Свет  = Δэл × тариф за кВт·ч
Итого = вода + свет + отопление + абонплата ЖКХ
```

Тарифы меняются на той же вкладке. Каждые показания запоминают тарифы, по которым
посчитаны, поэтому смена тарифа не пересчитывает прошлые месяцы. Чтобы строка
вводилась вручную, нажмите на неё на вкладке «Период» → «Вводить вручную».

Кнопка «Перенести показания из таблицы» загружает показания за январь–сентябрь
2026 (декабрь 2025 — как база для расчёта января).

## Синхронизация

1. Телефон и компьютер в одной сети (один роутер / Wi‑Fi).
2. На обоих вкладка «Синхронизация» → «Код синхронизации» — одинаковый код
   (кнопка «Сгенерировать» на одном, ввести этот же на другом).
3. Устройства находят друг друга сами (UDP‑broadcast, порт 47801) и обмениваются
   изменениями по HTTP (порт 47800). Если автопоиск в вашей сети не работает —
   «По IP» и адрес с другого устройства.
4. Синхронизация автоматическая: после каждой правки и каждые 20 секунд, пока
   приложение открыто. Каждое устройство раз в 5 секунд сообщает в сеть номер
   своей последней правки, поэтому другое устройство забирает изменения за
   несколько секунд, даже если до первого ему не достучаться. Кнопка в шапке —
   синхронизировать сразу.
5. Красный значок в шапке — только настоящие проблемы: неверный код, часы,
   или устройство в сети, но связаться с ним не выходит. Если телефон просто
   выключен или приложение на нём свёрнуто, это не ошибка.

Как устроено: каждая запись (расход, период, кредит…) имеет уникальный id и метку
времени последней правки (гибридные логические часы). Устройства передают только
изменения после прошлого обмена; если одну запись изменили на двух устройствах,
остаётся более поздняя правка. Удаления тоже синхронизируются. Все запросы и
ответы подписываются HMAC‑SHA256 общим кодом — чужое устройство в сети без кода
данные не прочитает и не изменит. (Трафик внутри домашней сети не шифруется,
только подписывается.)

**Windows:** при первом запуске появится окно брандмауэра — разрешите доступ
для **частных сетей**. Ваша Wi‑Fi сеть в Windows должна быть «Частной»
(Параметры → Сеть и Интернет → свойства сети).

Данные хранятся локально в JSON‑файле (путь показан внизу вкладки
«Синхронизация»; на Windows это `%APPDATA%\com.cash\cash\cash_data.json`).

## Резервные копии

Вкладка «Синхронизация» → «Резервные копии»:

- **«Создать резервную копию»** — все данные (периоды, расходы, кредиты,
  показания счётчиков, тарифы) сохраняются в файл `cash-backup-<дата>.json`.
  На Windows выбирается папка, на телефоне — папка или облако (Google Диск и т.п.).
  Название устройства, код синхронизации и список устройств в копию не входят.
- **«Восстановить из копии»** — данные на этом устройстве заменяются данными
  из файла (полностью, без слияния).
- **«Автокопии»** — перед каждой заменой данных устройство само сохраняет
  прежние данные (хранятся 20 последних). Их можно восстановить так же.

**Восстановленная копия имеет приоритет.** Когда устройства в следующий раз
синхронизируются, второе устройство не сливает данные, а целиком заменяет свои
данными восстановленной копии (свои перед этим сохраняет в автокопию) и
показывает сообщение «Данные заменены резервной копией» — с какого устройства
и когда её восстановили. Правки, сделанные на втором устройстве до этой
синхронизации, при этом теряются (остаются только в автокопии). Если позже
восстановить копию на другом устройстве, приоритет переходит к нему —
побеждает самое позднее восстановление.

Как устроено: у данных есть «поколение» — метка последнего восстановления
(HLC‑метка, сравнивается между устройствами). Устройство с более новым
поколением передаёт все данные целиком; изменения со старым поколением
не принимаются, чтобы в данные не вернулось то, чего нет в копии.

## Сборка

### В GitHub (основной способ)

После каждого push в ветку `main` GitHub Actions (`.github/workflows/build.yml`)
проверяет код (`flutter analyze`, `flutter test`), собирает APK и Windows‑версию
и публикует **релиз**: репозиторий → **Releases** → последний (Latest):

- `Cash-1.0.N.apk` — скачайте на телефон и установите
  (разрешите установку из неизвестных источников);
- `Cash-windows-1.0.N.zip` — распакуйте и запустите `Cash-windows\cash.exe`.

`N` — номер сборки (версия приложения 1.0.N). Хранятся 10 последних релизов. Ход сборки — вкладка **Actions** (около 10 минут).

**Ключ подписи APK (один раз).** Android ставит новую версию поверх старой,
только если обе подписаны одним ключом. Чтобы APK из GitHub ставились поверх
Cash, собранного раньше на компьютере, дайте GitHub тот же ключ:

1. В PowerShell на компьютере, где собирался APK, скопируйте ключ в буфер обмена:
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("$env:USERPROFILE\.android\debug.keystore")) | Set-Clipboard
   ```
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions**,
   вкладка **Secrets**, блок **Repository secrets** → **New repository secret**.
   Name: `ANDROID_DEBUG_KEYSTORE`, Secret — вставьте из буфера, **Add secret**.
   (Разделы Codespaces, Dependabot и Environment secrets сборке не видны;
   переменная с тем же именем на вкладке Variables тоже подойдёт.)
3. **Actions → build → Run workflow** — пересобрать с этим ключом.

Проверка: в описании релиза указан отпечаток ключа «Підпис APK (SHA-256)».
Отпечаток APK, который уже стоит на телефоне (если собирали на ПК), —
`python scripts\apk_cert.py dist\Cash.apk`. Совпадают — новый APK встанет
поверх старого.

Без секрета сборка тоже пройдёт, но APK будет подписан случайным ключом, и для
установки придётся сначала удалить старое приложение (данные вернутся
синхронизацией с компьютером или из резервной копии).

### На своём компьютере

Нужен Flutter SDK (стабильный, 3.38 или новее).

1. Установите [Flutter](https://docs.flutter.dev/get-started/install/windows) и добавьте `flutter\bin` в PATH.
2. Для Windows‑версии: Visual Studio 2022 Community с компонентом
   **«Разработка классических приложений на C++»**.
3. Для APK: Android Studio (ставит Android SDK), затем `flutter doctor --android-licenses`.
4. Проверьте: `flutter doctor`.
5. Запустите **`build.bat`** в этой папке. Результат — в `dist\`:
   - `dist\Cash-windows\cash.exe` — копируйте всю папку `Cash-windows` целиком;
   - `dist\Cash.apk` — перекиньте на телефон и установите
     (разрешите установку из неизвестных источников).

Только одна платформа: `build.bat -SkipAndroid` или `build.bat -SkipWindows`.

### Автосборка на компьютере после каждого коммита (не обязательно)

Теперь каждый коммит собирает GitHub, поэтому это нужно, только если хочется
собирать ещё и у себя. Запустите **`watch-build.bat`** и оставьте окно открытым (можно свёрнутым или
добавить в автозагрузку). Раз в 5 секунд оно проверяет, появился ли новый коммит,
и если да — запускает ту же сборку, что `build.bat`. Если коммит пришёл во время
сборки, следующей соберётся самая свежая версия.

- `dist\build-status.json` — результат последней сборки (`running` / `ok` /
  `failed`, коммит, время, последние строки вывода);
- `dist\log-build.txt` — полный вывод.

Если программа открыта из `dist\Cash-windows`, новая версия кладётся в
`dist\Cash-windows-new` (занятые файлы не трогаются).

Для разработки: `powershell -File scripts\prepare.ps1`, затем `flutter run -d windows`
или `flutter run` с подключённым телефоном.

iOS: этот же код собирается и под iPhone (`flutter create --platforms ios .` на Mac),
но установка на iPhone требует Mac и аккаунт Apple‑разработчика.

## Структура

```
lib/
  main.dart                 запуск, тема, локализация
  data/                     записи, HLC-часы, модели, хранилище (JSON), резервные копии
  logic/budget.dart         все расчёты периода (как в таблице)
  logic/utilities.dart      расчёт коммуналки по показаниям счётчиков
  sync/sync_service.dart    сервер, поиск устройств, обмен изменениями
  ui/                       экраны: бюджет, кредиты, период, синхронизация, резервные копии
test/                       проверка расчётов против таблицы, синхронизации, интерфейса
platform/                   наши правки поверх стандартных android/ и windows/ (в т.ч. значки)
icon/                       значок приложения 1024×1024 (рисуется скриптом scripts/make_icon.py)
scripts/                    prepare.ps1 (подготовка), build.ps1 (сборка)
.github/workflows/build.yml сборка в облаке GitHub
```

Папки `android/` и `windows/` создаются автоматически скриптом `prepare.ps1`
(команда `flutter create`), поэтому их нет в исходниках.
